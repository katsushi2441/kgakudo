# Kurage 学童保育ナビ — 設置のしかた

住所を入れると、その自治体の放課後児童クラブ（学童保育）の
クラブ数・登録児童数・待機児童数を返します。

**PHP 1ファイルとJSONだけで動きます。** データベースも常駐サーバーも外部APIサービスも要りません。

## 置き方（3分）

1. `kgakudo.php` と `kgakudo_data/` を、公開したいディレクトリにそのまま置く
2. その階層の `.htaccess` に次の1行を書く（heteml や一部の共有サーバーは既定が PHP 5.6 のため）

       AddHandler php-script .php

3. `https://あなたのドメイン/kgakudo.php/` を開く

以上です。書き込み権限も要りません（読み取りだけで動きます）。

## 動作条件

- PHP 7.4 以上（8.x で動作確認）
- `file_get_contents` で外部へ接続できること（住所の表記ゆれをそろえるために
  国土地理院の住所検索を使います。つながらない場合は入力された住所のまま判定します）

## 画面

| URL | 中身 |
| --- | --- |
| `/kgakudo.php/` | 住所を入れて判定 |
| `/kgakudo.php/waiting50` | 待機児童が50人以上の市町村の一覧 |
| `/kgakudo.php/area/<自治体名>` | 都道府県・指定都市などのページ |
| `/kgakudo.php/data` | CSV・JSONの配布 |
| `/kgakudo.php/api/check?q=住所` | JSONで受け取る |
| `/kgakudo.php/about` | 出どころの説明 |

## データの更新（年1回）

こども家庭庁が毎年12月ごろに新しい調査結果（PDF）を公表します。
同梱の `scripts/parse_cfa.py`（Python・pdftotext が必要）でPDFから表を取り出し、
できた JSON と CSV を `kgakudo_data/` に置き換えてください。

    python3 scripts/parse_cfa.py 新しいPDF --year 2026
    python3 scripts/to_csv.py --year 2026

`kgakudo.php` の先頭にある `$YEAR` を新しい年にすれば切り替わります。

## この道具の考え方

国の公表はPDFだけで、e-Statにも載っていません。市区町村名で数字が出ているのは
**待機児童が50人以上いる市町村だけ**です。それ以外の市町村については、
**「未公表」と書きます。推定した数字は出しません。**
「待機児童がいない」とも書きません。分からないことを、分からないと書く作りです。
